SurLeQuai
Vos horaires TER, directement sur le quai

APPLICATION INDÉPENDANTE
SurLeQuai est une application indépendante et non officielle. Elle ne représente aucune entité gouvernementale et n’est ni affiliée à un gouvernement ni mandatée par celui-ci. Elle n’est pas affiliée à la SNCF et n’est pas une application officielle de la SNCF.

SOURCE DES DONNÉES
Les horaires et les informations de circulation affichés proviennent de l’API publique SNCF. Leur disponibilité dépend des données fournies par cette API.
Présentation officielle de l’API SNCF :
https://numerique.sncf.com/ressources/api/
Informations officielles sur les données accessibles et les conditions d’accès :
https://numerique.sncf.com/faq/api/
L’utilisation de cette API ne constitue pas une affiliation à la SNCF ou à une entité gouvernementale.

Consultez les prochains départs TER en temps réel, avec affichage des retards et des voies lorsque ces informations sont disponibles. Simple, rapide, sans compte ni publicité.

FONCTIONNALITÉS
- Horaires temps réel (départs, retards, annulations, selon les données disponibles) ;
- Multi-trajets (domicile-travail, etc.) ;
- Widget sur l’écran d’accueil ;
- Mode hors ligne avec cache ;
- Ordre automatique matin/soir ;
- Mode sombre.

VIE PRIVÉE
- Aucun compte requis dans SurLeQuai ;
- Aucune publicité ;
- Aucun outil de suivi publicitaire ;
- Vos favoris et les horaires mis en cache sont conservés sur votre appareil.
Les recherches de gares et de trajets sont transmises à l’API SNCF via le proxy de SurLeQuai, ou directement à la SNCF si vous configurez une clé API personnelle (utilisateurs avancés).
